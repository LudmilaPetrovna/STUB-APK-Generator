# STUB-генератор из существующих приложений

Порой когда мы работаем с легаси, нам нужно максимально сохранить с ним совместимость, однако само приложение к этому времени может быть окончательно поломано. Это же имеет место быть, если мы работаем с приложением, которое делал кто-то другой, исходников которого мы не имеем, но нам надо сделать с ним какую-то совместимость. Или же, если приложение еще до конца не написано, а нам уже надо с ним интегрироваться. Чтобы не сталкиваться с уже существующими причудами приложения, проще всего сгенерировать stub-приложение, которое ничего не будет делать, но полностью сохранит свой контракт. Можно отлаживаться и не бояться чужих ошибок или наследия чужого кода.

# Как пользоваться

После установки всех зависимостей, просто запускаем:
```
perl gen.pl "путь/до/файла.apk"
```
На выходе будет сформирован файл вида `com.example.packagename.apk` и `com.example.packagename.apk.7z`

Все активити, сервисы, ресиверы и контент-провайдеры будут СОХРАНЕНЫ. Манифест остается оригинальный, 100% совместимость.

Не рекомендуется называть аналогично исходный файл приложения.

# Как работает внутри

Порядок работы:

1. Сначала приложение распаковывается при помощи apktool - это нужно для распаковки манифеста приложения
2. Потом распаковывается при помощи обычного unzip - мы не трогаем оригинальный манифест и ресурсы
3. Анализируется сертификат и создается одноименный
4. Копируются все ресурсы приложения в `new_app`. В принципе, можно было бы скопировать все файлы, кроме кода. Нужны как минимум XML-файлы, так как они могут быть частью контракта, к примеру, для подключения USB-устройств.
5. Анализируется манифест, смотрим package name, какие активити и сервисы надо сгенерировать
6. Генерируется код, из директории ref_code. Его можно править. К примеру, если мы тестируем приложение на вылет, то можно раскомментировать `throw new RuntimeException("Fatal");`
7. Компилирование сгенерированных java-файлов (директория `new_code`) в class-файлы (директория `obj`)
8. Конвертация скомпилированных файлов в DEX-формат
9. Упаковка в ZIP
10. Выравнивание, подписывание, упаковка в 7z

# Установка приложения

Для работы генератору нужны будут следующие утилиты и библиотеки:

* java - стандартная java, OpenJDK подойдет
* javac - компилятор java JDK
* zip/unzip - паковщик/распаковщик zip-архивов
* 7z - паковщик в 7z
* apksigner - утиль для подписи APK
* keytool - генерация ключей для подписи APK
* apksigtool - утиль для просмотра подписей
* dx - конвертор в DEX, есть в debian отдельным пакетом или в Android SDK
* adb - утиль для заливки полученной APK в телефон (из Android SDK, не обязательно)
* android.jar - файл из Android SDK, берите из последней API
* [apktool_2.12.1.jar](https://bitbucket.org/iBotPeaches/apktool/downloads/apktool_2.12.1.jar) - утиль для распаковки приложения

Чтобы быть уверенным, что все установлено правильно, можно запустить `deps_test.sh`, на выходе которого должно быть что-то вроде:
